# File Stats

Плагин для Visual Studio Code.

**Автор:** Бахмутов Александр Алексеевич, группа М3111 (Университет ИТМО)

## Описание

File Stats показывает статистику открытого файла и помогает подписывать файлы.

## Возможности

- **Статистика в строке состояния** — справа внизу постоянно видно число строк и слов в текущем файле, обновляется при наборе текста и смене вкладки.
- **Команда «File Stats: Показать статистику файла»** — показывает число строк (всего и непустых), слов и символов. Также вызывается кликом по строке состояния.
- **Команда «File Stats: Вставить шапку с автором»** — вставляет в начало файла комментарий с автором и текущей датой. Символ комментария выбирается по языку (`#` для Python, shell, YAML и т.п., иначе `//`).
- **Настройка `fileStats.author`** — имя автора для шапки (Settings → File Stats).

## Запуск

1. Открыть папку проекта в VS Code.
2. Нажать `F5` — откроется окно Extension Development Host с подключённым плагином.
3. Команды доступны через `Cmd+Shift+P` (macOS) / `Ctrl+Shift+P`.

Сборка `.vsix`: `npx @vscode/vsce package`.
